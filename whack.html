Engineering Sciences 50 · Final Project

Whack-A-Mole Light-Up Button Game

Team: Lyat Melese, Nimet Yesil, Victoria Zambrano, and Anya Zhang.

Image from the original team report.

PROJECT DOCUMENTATION

Read full report ↗

Original collaborative course report. Contributions are credited to the full team.

Challenge

Build a portable reaction game with illuminated buttons, four difficulty levels, scoring, and responsive player feedback.

System design

The team integrated buttons and LEDs with an Arduino, a buzzer, LCD screen, and microSD score storage. The report describes building and testing subsystems before combining them into a physical interface.

Design decisions

A resistor ladder reduced button pin usage compared with individually wired buttons. The team soldered interactive components onto protoboard for more robust connections and used a CSV file on microSD to preserve scores.
